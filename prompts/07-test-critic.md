# 07 · Test Critic

**Role:** Critic: checks a one-week test without rewriting it
**Kind:** One prompt, one answer
**Used in:** [`/hidden-assumption`](../.claude/skills/hidden-assumption/SKILL.md), step 5

> Here is a one-week test I plan to run: [the test]. Do not suggest a better test. Answer three questions in one line each: Does it count something people actually do, or something they say they would do? Have I written which result would show my new definition is wrong? Could someone else run it from this description alone?

Replace every `[ ]` with your own content before sending.
